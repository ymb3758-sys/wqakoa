# NFT Offer Bot (Telegram)

Бот для создания и рассылки NFT-офферов. Бизнес-менеджер через `/offer` выбирает получателя, шлёт ссылку на подарок и сумму; получателю приходит сообщение с кнопками **✅ Принять / ❌ Отклонить**. Вердикты логируются в SQLite и дублируются админу. При «Принято» — напоминание передать NFT на аккаунт-получатель вручную.

## Важно про передачу NFT
Бот **не может** сам переместить Telegram-NFT: коллектабл хранится в аккаунте-владельце, а принимать/передавать подарок может только сам держатель через официальный интерфейс (открыть слаг). Передача выполняется вручную владельцем аккаунта; бот лишь отслеживает вердикт и показывает, куда передать.

## Стек
- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev)

## Установка
```bash
cd offer-bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS
python bot.py
```

## Команды (только админ, кроме /start)
| Команда | Действие |
|---|---|
| `/offer` | создать оффер: выбрать получателя → пришли ссылку/слаг/название → сумма |
| `/recipients` | список получателей (id + имя) |
| `/add_recipient <имя>` | зарегистрировать текущий чат как получателя |
| `/target` | показать аккаунт-получатель передачи |
| `/set_target <ID> [метка]` | сменить аккаунт, на который передавать |
| `/send <текст>` | одноразовая отправка оффера всем получателям |

## Получатель
Нажимает `/start` боту (регистрируется). Получает оффер с кнопками «Принять / Отклонить». Ответ фиксируется, кнопки заменяются на «вы приняли/отклонили».

## .env
| Поле | Назначение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | ID админов через запятую |
| `ADMIN_LOG_CHAT_ID` | отдельный чат для дублирования вердиктов (опц.) |
| `DATABASE_PATH` | SQLite (по умолчанию `offers.db`) |

ID админа/получателя можно узнать у @userinfobot. Токен и ID пришлёшь — впишу и проверю запуск.
